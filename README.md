\# AI-Driven Adaptive Software Engineering and Intelligent Project Management System



\## 📌 Project Overview



The \*\*AI-Driven Adaptive Software Engineering and Intelligent Project Management System\*\* is an intelligent project management application designed to help software development teams monitor tasks, predict project risks, prioritize tasks, and receive AI-based recommendations.



The system combines \*\*Machine Learning, adaptive scheduling, task management, and a web dashboard\*\* into a single project management solution.



\---



\## 🎯 Objectives



\- Manage software development tasks efficiently

\- Track task priorities, deadlines, and status

\- Calculate overall project progress

\- Predict project risk using Machine Learning

\- Automatically prioritize important tasks

\- Generate intelligent project recommendations

\- Provide a web-based project management dashboard

\- Store and analyze project information



\---



\## 🚀 Key Features



\### 1. Task Management



The system allows users to:



\- Create tasks

\- Assign priorities

\- Set deadlines

\- Update task status

\- View all project tasks



Supported task statuses:



\- Pending

\- Completed

\- Delayed



\---
